# Language Translation: English to Hindi using Transformers

This repository contains scripts, model outputs, and evaluation metrics for English to Hindi translation using various transformer-based models. Model weights are saved in safetensors format and tracked with Git LFS.

## Project Structure

- **Scripts**: Contains Jupyter notebooks for model training and evaluation
- **Runs**: Contains the fine-tuned model weights and configurations
- **Output_files**: Contains evaluation metrics, comparison plots, and translation results
- **Results_and_plots**: Contains additional documentation of results

## Models Used

This project experiments with several transformer-based translation models:
- Marian MT
- mBART
- mT5

## Requirements

See `requirements.txt` for the dependencies needed to run the code in this repository.

## Note

Large model files (*.safetensors) are tracked using Git LFS. Make sure to have Git LFS installed when cloning this repository to properly download these files.
